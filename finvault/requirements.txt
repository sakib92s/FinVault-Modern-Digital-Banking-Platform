# FinVault · Requirements File
# This file lists all required dependencies and system components

========================
SERVER REQUIREMENTS
========================
PHP >= 8.0
MySQL >= 8.0
Apache / Nginx
mod_rewrite enabled

========================
PHP EXTENSIONS
========================
mysqli
pdo_mysql
mbstring
openssl
json
curl
fileinfo

========================
COMPOSER PACKAGES (OPTIONAL BUT RECOMMENDED)
========================
phpmailer/phpmailer
tecnickcom/tcpdf

========================
FRONTEND DEPENDENCIES (CDN BASED)
========================
Chart.js
qrcodejs

========================
DIRECTORY PERMISSIONS
========================
/uploads      (read/write)
/logs         (read/write)
/reports      (read/write)

========================
CONFIG REQUIREMENTS
========================
SMTP_ENABLED = true (optional)
Gmail App Password (for SMTP)
/includes/config.php properly configured

========================
NOTES
========================
- Without PHPMailer: emails fallback to logs/mail.log
- Without TCPDF: PDFs render as printable HTML
- No external APIs required for core functionality
